🔮 Magic 8 Ball

What are you building?

A game where someone asks a question and gets a randomly chosen response.

Make it yours

It doesn’t have to be a Magic 8 Ball. Turn it into a fortune teller, advice machine, mysterious oracle, terrible life coach, compliment generator, or something completely different.

Success looks like

  • The player can ask a question
  • The game chooses a random response
  • Your version feels like your own

Want to go further?

  • Write your own responses
  • Change the message when no question is entered
  • Add different types of answers
  • Add an animation or sound
  • Stretch: Make certain questions trigger special responses

Helpful Tricks

Pick something randomly

First, choose a random spot in an array:

let randomIndex = Math.floor(Math.random() * answers.length);

Then grab the answer in that spot:

let answer = answers[randomIndex];

Read what someone typed

let question = questionInput.value;

Change text on the page

answerDisplay.textContent = answer;

🏎️ Race Cars

What are you building?

A game where players use the keyboard to move racers toward a finish line.

Make it yours

Race cars, animals, spaceships, shopping carts, or anything else you can move across the screen.

Success looks like

  • The keyboard moves the racers
  • Someone can reach the finish line
  • Your version feels like your own

Want to go further?

  • Change the controls
  • Add a second player
  • Add obstacles or boosts
  • Stretch: Create a new rule that changes how the race works

Helpful Tricks

  • Listen for keydown
  • Change an element’s left position
  • Keep each racer’s position in a variable
  • Check whether someone crossed the finish line

🧠 Memory

What are you building?

A matching game where the player flips cards and tries to find pairs.

Make it yours

Choose what players are matching: animals, emojis, characters, food, your own drawings, or anything else you want.

Success looks like

  • The player can flip cards
  • Matching pairs stay revealed
  • The game knows when a pair matches

Want to go further?

  • Keep track of the number of tries
  • Add a timer
  • Add an effect when a match is found
  • Stretch: Add a new rule that changes how the game works

Helpful Tricks

Keep your cards in an array

let cards = [
  "🐶", "🐶",
  "🐸", "🐸",
  "🐱", "🐱"
];

Remember which cards were clicked

let firstCard;
let secondCard;

Check for a match

if (firstCard === secondCard) {
  console.log("Match!");
}

✊ Rock Paper Scissors

What are you building?

A game where the player chooses a move and plays against the computer.

Make it yours

Keep Rock Paper Scissors, or invent your own three-way battle: fire, water, grass; wizard, knight, dragon; cat, dog, squirrel; or something completely different.

Success looks like

  • The player can choose a move
  • The computer chooses a move
  • The game decides who wins

Want to go further?

  • Keep score
  • Add a best-of-three mode
  • Add images or animations for each move
  • Stretch: Invent your own moves and rules

Helpful Tricks

Give the computer some choices

let choices = [
  "rock",
  "paper",
  "scissors"
];

Let the computer choose randomly

let randomIndex =
  Math.floor(Math.random() * choices.length);

let computerChoice =
  choices[randomIndex];

Decide who wins

if (playerChoice === computerChoice) {
  result.textContent = "Tie!";
} else if (
  playerChoice === "rock" &&
  computerChoice === "scissors"
) {
  result.textContent = "You win!";
} else {
  result.textContent = "Computer wins!";
}

🚫 The Impossible Game

What are you building?

A game where the rules are hidden, strange, or constantly changing.

Make it yours

There are no normal rules. A button might disappear, the wrong-looking choice might be correct, or winning one round might completely change what happens next.

Success looks like

  • The player can make choices
  • Different choices lead to different outcomes
  • The game has at least a few stages or surprises

Want to go further?

  • Add fake buttons or misleading instructions
  • Change the rules halfway through
  • Add secret ways to win or lose
  • Stretch: Create a moment where the player has to figure out a rule you never explained

Helpful Tricks

Show or hide something

triangle.style.display = "none";

Change what the player sees

message.textContent = "Wrong. Obviously.";

Make choices lead somewhere different

if (choice === "triangleTwo") {
  showNextRound();
} else {
  loseGame();
}

Keep track of what stage you’re on

let round = 1;
