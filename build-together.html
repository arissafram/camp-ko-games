Build Together: Clicker

One game the whole class builds and evolves together, all week long.

Source Code ↗

What Are We Building?

Right now, Clicker is as simple as it gets: click a button and your score goes up. That’s the whole game.

This section changes as the game does — check back here after every new feature to see what Clicker can do now.

Pseudocode

Before we write any JavaScript, we plan it out together as a class. Every plan answers the same four questions:

  • What appears on screen?
  • What does the game need to remember?
  • What makes something happen?
  • What happens next?

Our plan for today

START with a score of 0
SHOW the score on the screen

WHEN the player clicks the button:
    add 1 to the score
    show the new score

WHEN the player clicks reset:
    set the score back to 0
    show the new score

Today’s Goal

  • Clicking the button increases the score by 1.
  • The score is always visible on the screen.
  • A reset button sets the score back to 0.

What We Learned

  • Variables — remember the score.
  • Functions — reuse the code that updates the screen.
  • Event listeners — react when someone clicks a button.

What Should We Add Next?

Right now, the game never ends — you could click forever. How could we make it stop after 10 seconds?
