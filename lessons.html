Day 1 — Variables, Functions, Events

Concept 1

Variables

A variable is a name that stores a value.

let score = 0;
score = score + 1;
console.log(score); // 1

let score = 0 creates a box called score and puts the number 0 inside it. The next line adds 1 to whatever is already in that box.

Watch out: Forgetting let or const when you first create a variable. Always declare it before you use it.

Concept 2

Functions

A function is a named block of code you can run whenever you want.

function addPoint() {
  score = score + 1;
  updateDisplay();
}

addPoint(); // runs the code inside

Writing addPoint() runs all the code inside the function. You can call it as many times as you like.

Watch out: Defining a function does nothing on its own — you have to call it with () at the end.

Concept 3

Events

An event is something that happens in the browser — a click, a key press, a timer firing.

const button = document.getElementById('myButton');

button.addEventListener('click', function () {
  addPoint();
});

addEventListener tells the browser: "When this button is clicked, run this function." The function inside is only called when the event happens.

Watch out: Spelling the event name wrong — it's 'click', not 'Click' or 'onclick'.

Day 2 — Arrays, Objects, Conditionals

Concept 4

Arrays

An array is a list of values stored in order.

const colors = ['red', 'green', 'blue'];

console.log(colors[0]); // 'red'
console.log(colors.length); // 3

colors.push('yellow'); // adds to the end

Items are numbered starting at 0, not 1. colors[0] gives you the first item, colors[2] gives you the third.

Watch out: Arrays start at index 0. The last item is at index length - 1.

Concept 5

Objects

An object groups related values together under one name.

const question = {
  text: 'What does CSS stand for?',
  answers: ['Cascading Style Sheets', 'Computer Style Script'],
  correct: 0
};

console.log(question.text);    // 'What does CSS stand for?'
console.log(question.correct); // 0

Each piece of data has a key (like text) and a value. Use a dot to read a value: question.text.

Watch out: Forgetting the comma between key-value pairs. Every pair except the last one needs a comma after it.

Concept 6

Conditionals

A conditional runs different code depending on whether something is true or false.

if (answer === correct) {
  score = score + 1;
  showFeedback('Correct!');
} else {
  showFeedback('Not quite.');
}

Use === (triple equals) to compare two values. If the condition is true, the first block runs. If it's false, the else block runs.

Watch out: Using = (assignment) instead of === (comparison). One sets a value; three checks it.

Day 3 — Loops, Randomness

Concept 7

Loops

A loop repeats a block of code a set number of times (or once for each item in a list).

// Repeat 5 times
for (let i = 0; i < 5; i++) {
  console.log('i is', i);
}

// Loop through an array
const fruits = ['apple', 'banana', 'cherry'];
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

i starts at 0, and i++ adds 1 each time. The loop keeps running as long as i < 5.

Watch out: An infinite loop — if the condition never becomes false, the browser will freeze. Always make sure i is changing each time.

Concept 8

Randomness

Math.random() gives you a random decimal between 0 and 1 every time you call it.

// Random decimal: 0.0 to 0.999...
console.log(Math.random());

// Random whole number: 0 to 8
let n = Math.floor(Math.random() * 9);

// Random item from an array
const items = ['cat', 'dog', 'fish'];
let pick = items[Math.floor(Math.random() * items.length)];

Math.floor rounds down to the nearest whole number. Multiplying by a number controls how big the result can get.

Watch out: Off-by-one — Math.random() * 3 gives 0, 1, or 2 after Math.floor. Multiply by the count, not the max index.
