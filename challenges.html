Challenges

Bonus tasks for when you finish early. No grades, no pressure.

Easy

One small change. Build confidence, try something new.

Clicker: Make your score start at 10 instead of 0. Where do you set the starting value?
Clicker: Make the button say something other than "Click!" — change the text in the HTML.
Quiz: Add one new question to the questions array. Copy the format of an existing one.
Whack-a-Mole: Change the mole emoji to something else — a star, a smiley, anything.
Racing: Change the step size so each keypress moves the bar by 5% instead of 2%.

Medium

Add a small feature to a working game.

Clicker: Add a reset button that sets the score back to 0. You'll need a new button in HTML and a new event listener in JS.
Clicker: Show a message when the score hits 50: "You hit 50!" Check the score inside the click handler with an if statement.
Quiz: Show how many questions are left at the top of each question card. You already have questions.length and current available.
Whack-a-Mole: Make the moles appear faster as the score goes up. Decrease the interval time every 5 points.
Memory: Show a "New best!" message if the player beats their lowest move count. Store the best score in a variable.

Creative

Open-ended. No single right answer — experiment.

Theme your game. Change all the colors, fonts, and button text to match something you love — a sport, a show, a color scheme. Edit the CSS file.
Add a title screen. Show a welcome screen before the game starts — with a title and a "Play" button. Hide it when the player clicks Play.
Make your own quiz. Replace all 10 questions with a quiz about something you know: your favorite show, sports trivia, random facts.
Add sound effects. Use the Audio object to play a beep on correct answers or a click sound when the button is pressed. Search: "JavaScript play sound."

Mystery

Revealed by your instructor mid-week. Click to unlock.

Mystery Challenge 1 — locked
Multiplier mode. Add a multiplier to the clicker game. Every 10 clicks, the multiplier goes up by 1. Each click adds score += multiplier instead of 1. Display the current multiplier on screen.
Mystery Challenge 2 — locked
Wrong answers only. Edit the quiz so the correct answer is always the wrong one — meaning the code marks the correct index as wrong and every other answer as right. (Hint: flip the === to !==.)
Mystery Challenge 3 — locked
Reverse racing. Edit the racing game so pressing Q and P moves both bars — but pressing Q also slows down Player 2 by 1%, and pressing P slows down Player 1. First to 100% still wins, but now you can sabotage each other.
