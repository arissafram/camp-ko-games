The Big Picture

NameJobFileExample
HTML
Bones		 Structure — what exists on the page .html <h1>, <button>, <div>
CSS
Skin		 Appearance — what things look like .css color, font-size, background
JavaScript
Action		 Behavior — what things do .js click handler, score++

Change what something is → edit HTML. Change what it looks like → edit CSS. Change what it does → edit JS.

Conditionals

if (score > 10) {
  // runs when score is more than 10
} else if (score === 10) {
  // runs when score is exactly 10
} else {
  // runs in every other case
}
OperatorMeaning
===Equal to (use this, not ==)
!==Not equal to
>   <Greater than / less than
>=   <=Greater or equal / less or equal
&&And (both must be true)
||Or (at least one must be true)

Loops

// Repeat 5 times
for (var i = 0; i < 5; i++) {
  console.log(i); // 0, 1, 2, 3, 4
}

// Loop through an array
var colors = ['red', 'green', 'blue'];
for (var i = 0; i < colors.length; i++) {
  console.log(colors[i]);
}

// While loop
var count = 10;
while (count > 0) {
  count--;
}
