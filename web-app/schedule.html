Schedule

See what we're learning, building, and creating each day.

Monday

Think Like a Programmer

Goals

  • Understand how HTML, CSS, JavaScript, and the DOM work together to build a webpage.
  • Plan and design the first version of your game before writing code.

Today's Plan

  • Meet your teammates & create team values
  • Talk about what HTML, CSS, JavaScript, and the DOM each do
  • Learn three different ways to update styles: inline, stylesheet, and DOM manipulation
  • Use dev tools to inspect your web page
  • Begin designing your game board
  • Learn how programmers use pseudocode to plan before they code

Vocab

HTML CSS JavaScript DOM pseudocode

Tuesday

Make It Work

Goals

  • Learn how JavaScript remembers information and responds to the player.
  • Build the first playable version of your game.

Today's Plan

  • Review: HTML, CSS, JavaScript, and the DOM
  • Use variables to store the information your game needs to remember
  • Meet the Console and use console.log() to see what your code is doing
  • Learn how functions group instructions and make things happen
  • Add your first event listeners to make the game respond to clicks
  • Watch your game come to life as JavaScript updates the page

Vocab

console.log variable function event listener string number

Wednesday

Give Your Game Rules

Goals

  • Teach your game to make decisions using conditions and booleans.
  • Decide how players win, lose, or finish the game.

Today's Plan

  • Review: variables, functions, and event listeners
  • Learn how booleans and if statements help games make decisions
  • Explore comparison and logical operators
  • Decide how your game works—can the player win, lose, or run out of time?
  • Practice new ways to debug and solve problems when things don't work

Vocab

boolean conditional comparison operator logical operator timer

Thursday

Make It Yours

Goals

  • Add new features and make your game uniquely yours.
  • Test your game, fix bugs, and help others improve theirs.

Today's Plan

  • Review: conditionals, if/else statements, booleans
  • Add new ideas like timers, high scores, moving targets, keyboard controls, or your own creative twists
  • Learn a few fun tricks like Math.random() and setTimeout() to make your game more interesting
  • Play each other's games, share ideas, and help fix bugs
  • Keep improving, testing, and polishing your game

Vocab

MVP testing feedback iteration polish

Friday

Finish and Share

Goals

  • Finish and polish your game so others can play it.
  • Share what you built and celebrate everyone's creativity.

Today's Plan

  • Review: everything we've learned this week!
  • Add the finishing touches to your game
  • Test your game and fix any last bugs
  • Practice showing someone how your game works
  • Showcase! Play each other's games and celebrate everything we built together

Vocab

MVP demo polish showcase deploy
