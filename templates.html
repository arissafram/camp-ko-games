Templates

Starter, guided, and finished files for each game.

How to get the files

  1. Go to github.com/arissafram/camp-ko-games
  2. Click the green Code button, then Download ZIP
  3. Unzip the file in your Downloads folder
  4. Open the templates/ folder — pick a game
  5. Open starter/index.html in your browser to begin

Starter = blank JS with TODO comments  |  Guided = ~50% written with hints  |  Finished = fully working (teacher reference)

Clicker

Click a button to increase your score. High score saved between sessions.

Concepts: variables, events, functions

Starter Guided Finished

Quiz

10 questions, 4 answers each. Instant feedback and a score at the end.

Concepts: arrays, objects, conditionals

Starter Guided Finished

Whack-a-Mole

Moles pop up randomly in a 3×3 grid. Click them before they disappear. 30-second game.

Concepts: timers, randomness, events

Starter Guided Finished

Memory

Flip cards to find matching pairs. 4×4 grid, 8 pairs. Tracks moves taken.

Concepts: arrays, state tracking, loops

Starter Guided Finished

Racing

2-player game on one keyboard. Q key vs P key. First to 100% wins.

Concepts: keyboard input, conditionals, DOM
