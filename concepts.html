JS Concepts

Everything you need to build your game, all in one place.

HTML + CSS + JavaScript

Websites are built with three main tools:

  • HTML puts things on the page.
  • CSS changes how things look.
  • JavaScript makes things happen.

HTML

<button>Click me</button>

CSS

button {
  font-size: 24px;
}

JavaScript

console.log("Hello!");

Try it

Change the button text, its style, and the message in the console.

The DOM

The DOM is how JavaScript sees and interacts with your webpage.

JavaScript can find something on the page:

let message = document.getElementById("message");

Then change it:

message.textContent = "Something happened!";

Try it

Find an element on your page and change its text.

console.log()

console.log() lets us see what our JavaScript is doing.

let score = 10;

console.log(score);

You can print messages too:

console.log("The game has started!");

Try it

Make the console show your name and the value of a variable.

Variables

A variable lets us remember something.

let score = 0;
let playerName = "Pickle";
let gameOver = false;

Variables can remember all kinds of things in a game: scores, names, lives, speed, and more.

Try it

Change the player’s name and starting score.

Strings, Numbers + Booleans

JavaScript can remember different types of information.

let playerName = "Pickle";  // string
let score = 10;             // number
let gameOver = false;       // boolean
  • String = text
  • Number = a number
  • Boolean = true or false

Try it

Create one variable of each type.

Functions

A function is a set of instructions we can use whenever we need it.

function celebrate() {
  console.log("You did it!");
}

To use it, we call the function:

celebrate();

Functions can tell your game what to do when you score, click something, start a round, or win.

Try it

Create a function that prints your own message.

Events + Event Listeners

An event is something that happens. A player might click a button, press a key, or submit an answer.

An event listener waits for an event and tells JavaScript what to do next.

button.addEventListener("click", celebrate);
WHEN the button is clicked → DO this

Try it

Connect a button to one of your functions.

Changing the Page

JavaScript can change your webpage while someone is using it.

let message = document.getElementById("message");

message.textContent = "You win!";

You can change text, images, styles, and more.

Try it

Make a button change something on your page.

User Input

Your game can use information that a player types.

let playerName = nameInput.value;

console.log(playerName);

This lets players become part of what happens in your program.

Try it

Add an input and print what the player typed.

Arrays

An array stores a list of things.

let animals = ["dog", "cat", "raccoon", "frog"];

Games use arrays for things like characters, cards, questions, choices, or possible answers.

Try it

Make an array of five things you like.

Objects

An object keeps related information together.

let player = {
  name: "Pickle",
  lives: 3,
  score: 10
};

Each piece of information has a property and a value.

Try it

Create an object for your own game character.

forEach

forEach does something once for every item in an array.

let animals = ["dog", "cat", "frog"];

animals.forEach(function(animal) {
  console.log(animal);
});

Instead of writing the same instructions over and over, we can tell JavaScript to do them for each item.

Try it

Use forEach to print every item in your array.

if Statements

if lets JavaScript make a decision.

if (score === 10) {
  console.log("You win!");
}
IF this is true → DO this

Games use decisions everywhere: winning, losing, matching cards, checking answers, and more.

Try it

Change the score and see when the message appears.

Conditions

A condition is the question JavaScript checks.

score === 10

That condition can be either true or false.

Try it

What happens if you change 10 to another number?

Input → Rules → Output

A simple way to think about a game:

INPUT What does the player do?
RULES What does the game decide?
OUTPUT What happens next?

For example: Player clicks a mole → Is it still visible? → Add a point

Use this pattern when you’re not sure how to build a feature.

Timers

JavaScript can make something happen after a certain amount of time.

setTimeout(function() {
  console.log("Time's up!");
}, 2000);

2000 means 2 seconds. Timers can control rounds, animations, enemies, messages, and more.

Try it

Change how long JavaScript waits.

Movement

Games can respond when a player presses a key.

document.addEventListener("keydown", function(event) {
  console.log(event.key);
});

From there, your code can decide how your character or object should move.

Try it

Press different keys and watch the console.

Sound + Animation

Games don’t just have to work — they can feel fun too.

JavaScript can trigger sounds, animations, visual effects, and other finishing touches.

Use these when your game works and you’re ready to add something extra.

Pseudocode

Pseudocode means planning your code in normal language first.

You don’t need to know the JavaScript yet.

START with a score of 0

WHEN the player clicks:
    add 1 to the score
    show the new score

Now we know what our program needs to do before figuring out exactly how to code it.

Try it

Write the steps for one part of your game without using any JavaScript.

Breaking Down a Problem

Big problems are easier when we turn them into little problems.

Instead of “Build a game,” ask:

  • What does the player do?
  • What does the game need to remember?
  • What happens next?

Then solve one piece at a time.

Debugging

A bug is something in your code that isn’t working the way you expected. Debugging means figuring out why.

When something doesn’t work:

  1. Read the error.
  2. Check the console.
  3. Find where the problem starts.
  4. Change one thing.
  5. Try again.

Bugs are part of programming. Finding them is part of programming too.

Testing

Don’t wait until your game is finished to test it.

Play it. Break it. Give it to someone else.

  • Does it work?
  • Is anything confusing?
  • What happens if I do something unexpected?

Then make it better.
