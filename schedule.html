Schedule

August 3–7, 2026.

Day 1

Web Foundations + JavaScript Makes Things Happen

Monday, August 3

Morning

Intro to HTML, CSS, and JavaScript. Live coding: bones, skin, action. Scratchpad experiments.

Afternoon

Variables, functions, and events. Start building the clicker game.

Final block

Finish clicker game. Share screens — what did you build?

Goals

  • Understand what HTML, CSS, and JavaScript each do
  • Write a variable and change it with a button click
  • Build a working clicker game

Vocab

variable function event addEventListener DOM console.log

Day 2

Games Need Decisions

Tuesday, August 4

Morning

Arrays and objects — storing lists and grouped data. Debugging walkthrough.

Afternoon

Conditionals (if/else). Start building the quiz game.

Final block

Finish quiz game. Add your own questions.

Goals

  • Store a list of questions in an array
  • Use an if/else to check if an answer is correct
  • Build a working quiz game

Vocab

array object index if / else === loop

Day 3

Movement + Randomness

Wednesday, August 5

Morning

Math.random, setInterval, keyboard events. Build whack-a-mole or memory game.

Afternoon

Choose your final project. Pick a template and start customizing.

Final block

Work on final project. Ask questions, experiment.

Goals

  • Use Math.random to make something unpredictable
  • Use setInterval to make something happen on a timer
  • Start your final project

Vocab

Math.random Math.floor setInterval clearInterval keydown

Day 4

Build Day

Thursday, August 6

Morning

Full build time. Debugging clinic — bring your broken code.

Afternoon

Keep building. Add a challenge feature if you're done.

Final block

Project checkpoint — does it run? What's left to polish?

Goals

  • Have a playable, working game by end of day
  • Fix at least one bug you found yourself
  • Know what you want to improve on Day 5

Vocab

bug console.log debugger iteration

Day 5

Pizzazz + Showcase

Friday, August 7

Morning

Polish your game — sounds, animations, colors, a title screen.

Afternoon

Final prep. Practice demoing your game to someone else.

Final block

Arcade showcase for parents and friends. Everyone presents.

Goals

  • Polish your game so it feels finished
  • Be able to explain what your code does
  • Demo your game to the room

Vocab

animation classList Audio localStorage
