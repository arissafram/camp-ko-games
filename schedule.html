Schedule

See what we're learning, building, and creating each day.

Monday

Day 1 — Think Like a Programmer

"Before we write code, we figure out what we want it to do."

Goals

  • Break an idea into steps with pseudocode
  • Learn the building blocks of JavaScript
  • Start our clicker game together

Morning — Learn + Build Together

  • How HTML, CSS, and JavaScript work together
  • Pseudocode: breaking an idea into steps
  • Plan our clicker game together
  • Variables: remember the score
  • Functions: give the game instructions
  • Events: make something happen on a click
  • DOM basics: update what we see on screen
  • Start building the clicker together

After Lunch — Review + Explore

  • Review the morning and answer questions
  • Look through the game choices
  • Break down how some of the games work
  • Start pseudocoding your own game

Late Afternoon — Choose + Plan

  • Choose your game
  • Finish your first pseudocode plan
  • Explore your starter files
  • Decide what you need to make work first

Vocab

pseudocode variable function event DOM

Tuesday

Day 2 — Remember, Change, Repeat

"Now we can make our games remember things and change what happens on screen."

Goals

  • Add more possibilities to our clicker
  • Learn how to store and work with groups of things
  • Start turning your game plan into code

Morning — Learn + Build Together

  • Changing things on the page with the DOM
  • Arrays: keeping a list of things
  • Random choices
  • forEach when it naturally helps
  • Test and debug what we build

After Lunch — Review + Build

  • Review and questions
  • Talk about where today's concepts could show up in different games
  • Start turning personal-game pseudocode into code
  • Begin building the core game

Late Afternoon — Build Your Game

  • Personal game work
  • Get the basic interaction working
  • Test, debug, and ask for help

Vocab

array DOM random forEach

Wednesday

Day 3 — Give Your Game Rules

"Games get interesting when they can make decisions."

Goals

  • Add rules and logic to our clicker
  • Combine the JavaScript tools we've learned
  • Get the main parts of your own game working

Morning — Learn + Build Together

  • Conditionals: giving the game rules
  • Game state: remembering what is happening
  • Timers where useful
  • Combining variables, functions, events, arrays, and DOM changes
  • Debugging together

After Lunch — Review + Build

  • Review and questions
  • Debug a problem together
  • Add rules and logic to personal games
  • Keep building

Late Afternoon — Build Your Game

  • Personal game work
  • Focus on getting the main game loop/interaction working
  • Debug and get help when stuck

Vocab

conditional if / else game state timer debugging

Thursday

Day 4 — Make It Yours

"Once it works, you get to decide what makes it yours."

Goals

  • Test, debug, and improve what you've built
  • Customize your game
  • Add something extra

Morning — Make It Better

  • Combine concepts we already know
  • Debug and test
  • Improve code that already works
  • Learn how to figure out something we don't know
  • Add one fun feature to the clicker

After Lunch — Make It Yours

  • Make it work → make it yours → add something extra
  • Customize things like images, colors, text, sounds, animations, rules, difficulty, or surprises
  • Pick what matters most for your game

Late Afternoon — Build + Test

  • Personal game work
  • Peer testing
  • Fix bugs
  • Keep customizing and adding extras

Vocab

debugging testing customization iteration

Friday

Day 5 — Ship It!

"It doesn't have to be finished forever — it just has to be ready to share."

Goals

  • Finish and test your MVP
  • Practice showing and explaining your game
  • Share what you built

Morning — Finish + Polish

  • Finish the most important parts of the game
  • Fix bugs
  • Test with other people
  • Add polish or extras if there is time
  • Prepare to explain what you built

After Lunch — Test + Practice

  • Final testing
  • Fix important bugs
  • Practice showing the game
  • Pick something you want to tell people about what you built or learned

Late Afternoon — Showcase

  • Share games
  • Show how they work
  • Talk about something you figured out or made your own
  • Celebrate everyone's work

Vocab

MVP testing polish iteration
