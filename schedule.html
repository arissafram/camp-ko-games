Day 1 — Web Foundations + JavaScript Makes Things Happen

"A computer only does what you tell it."

Goals

  • Understand the roles of HTML, CSS, and JavaScript
  • Learn the basics of variables, functions, and events
  • Make a webpage respond to user actions
  • Practice breaking problems into small, specific steps

Morning

  • Meet the team & create our class principles
  • Learn how HTML, CSS & JavaScript work together
  • Variables: strings, numbers & booleans
  • Experiment with functions

After Lunch

  • Make webpages interactive with events
  • Learn how to plan with pseudocode
  • Let's pseudocode

Afternoon

  • Explore the game choices
  • Choose your game
  • Start planning

Vocab

variable string number boolean function event event listener DOM console.log pseudocode

Day 2 — Teaching Computers to Remember

"Games need to remember things."

Goals

  • Understand how JavaScript stores information
  • Recognize when to use arrays and objects
  • Learn how to work with lists of information
  • Use what you learn in your game

Morning

  • Arrays & objects
  • Meet forEach
  • Work on your game

After Lunch

  • Challenge: Make a list come alive
  • Practice arrays & forEach
  • Work on your game

Afternoon

  • Review & questions
  • Work on your game

Vocab

array object property value array method forEach

Day 3 — Making Games Interactive

"Games make decisions and react to players."

Goals

  • Make programs respond to players
  • Understand how games make decisions
  • Add rules and interactions to your game
  • Practice testing and fixing your code

Morning

  • Input → rules → output
  • Make decisions with if
  • Timers & movement
  • Work on your game

After Lunch

  • Challenge: Create game rules
  • Practice conditions & if statements
  • Work on your game

Afternoon

  • Review & questions
  • Work on your game
  • Test & debug

Vocab

if statement condition timer input / output debugging
