Schedule

See what we're learning, building, and creating each day.

Monday

Think Like a Programmer

Goals

  • Understand what HTML, CSS, and JavaScript each do
  • See how a webpage is built by exploring the DOM
  • Learn how programmers plan with pseudocode
  • Design the first version of your game board

Today's Plan

  • Meet your teammates & create team values
  • Learn what HTML, CSS, JavaScript. Talk about the DOM!
  • Use dev tools to inspect your game
  • Begin designing your game board
  • Learn how programmers use pseudocode to plan before they code
  • Plan the first version of your game

Vocab

HTML CSS JavaScript DOM pseudocode

Tuesday

Make It Work

Goals

  • Learn how JavaScript remembers information
  • Make the game respond to a player
  • Change what appears on the screen
  • Build a simple, playable version of the game

Today's Plan

  • Review our game board and the plan we made on Monday.
  • Use a variable to remember the player's score.
  • Put instructions inside functions so they can be used again.
  • Use an event listener to make something happen when the player clicks.
  • Update the score on the screen using JavaScript and the DOM.
  • Add a way to reset the game and play again.
  • Test the game, find problems, and debug them together.

Vocab

variable function event event listener DOM debugging

Wednesday

Give Your Game Rules

Goals

  • Teach the game to make decisions
  • Decide when and how the game begins and ends
  • Explore different ways a player can control the game
  • Combine the JavaScript tools we have learned

Today's Plan

  • Review, play, and debug what we built on Tuesday.
  • Use conditionals to tell the game what should happen in different situations.
  • Add a timer or another way for the game to end.
  • Decide how players control your version—with clicks, keys, or something else.
  • Decide what the player is trying to accomplish.
  • Test different rules and see how they change the game.
  • Fix bugs and keep improving the main interaction.

Vocab

conditional boolean comparison operator logical operator timer

Thursday

Make It Yours

Goals

  • Make creative choices about how the game works
  • Add something new using the concepts we have learned
  • Test, debug, and improve the game
  • Help classmates by sharing ideas and feedback

Today's Plan

  • Choose one feature or idea that will make your version different.
  • Decide whether your game is for one player, two players, or even more.
  • Experiment with mouse clicks, keyboard controls, moving objects, or other interactions.
  • Add a goal, high score, timer, challenge, or surprise.
  • Keep improving the game's colors, images, text, sounds, and style.
  • Play someone else's game and give helpful feedback.
  • Use what you learn to fix, simplify, or improve your own game.

Vocab

MVP testing feedback iteration polish

Friday

Finish and Share

Goals

  • Finish the most important parts of the game
  • Test and prepare it for other people to play
  • Practice explaining what you created
  • Share and celebrate everyone's work

Today's Plan

  • Decide what needs to be finished and what can wait.
  • Test your full game from beginning to end.
  • Fix bugs that make it difficult to play.
  • Add a few final touches without starting something too big.
  • Practice showing how your game works and explaining one choice you made.
  • Play each other's games and share a rose, bud, and thorn.
  • Share our finished games and celebrate how different they became.

Vocab

MVP test polish demo deploy
