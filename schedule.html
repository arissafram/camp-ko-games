Schedule

See what we're learning, building, and creating each day.

Monday

Think Like a Programmer

"Before we write code, we figure out what we want it to do."

Goals

  • Break an idea into steps with pseudocode
  • Learn the building blocks of JavaScript
  • Start our clicker game together
  • Choose your game

Morning — Learn + Build Together

  • Intros & team goals
  • HTML, CSS & JavaScript
  • Think It Through: Pseudocode
  • Build Together: Begin Clicker game while learning variables, functions, events & the DOM

Midday — Review + Explore

  • Review & Questions
  • Choose your game!
  • Start pseudocoding your game

Afternoon — Choose + Plan

  • Keep pseudocoding
  • Explore your starter files
  • Plan your first steps

Vocab

pseudocode variable function event DOM

Tuesday

Remember, Change, Repeat

"Now we can make our games remember things and change what happens on screen."

Goals

  • Add more possibilities to our clicker
  • Learn new ways to store and use information
  • Start building your own game

Morning — Learn + Build Together

  • Icebreaker
  • Build Together: Arrays, random choices & forEach
  • Debug Together: Test, break & fix

Midday — Review + Build

  • Review & Questions
  • Connect the Concepts: Find where today's concepts fit in your game
  • Personal Game Work: Turn your pseudocode into JavaScript

Afternoon — Build Your Game

  • Get your basic interaction working
  • Test & debug
  • Ask for help

Vocab

array DOM random forEach

Wednesday

Give Your Game Rules

"Games get interesting when they can make decisions."

Goals

  • Teach our clicker to make decisions
  • Combine the JavaScript tools we've learned
  • Get the main parts of your game working

Morning — Learn + Build Together

  • Icebreaker & review
  • Build together
  • Debug together

Midday — Review + Build

  • Review & Questions
  • Apply It: Find where your game needs rules & decisions
  • Personal Game Work: Add logic to your game

Afternoon — Build Your Game

  • Get your main game interaction working
  • Add rules & logic
  • Test, debug & ask for help

Vocab

conditional comparison operator logical operator timer debugging

Thursday

Make It Yours

"Once it works, you get to decide what makes it yours."

Goals

  • Test, debug & improve your game
  • Make your game your own
  • Add something extra

Morning — Learn + Build Together

  • Icebreaker & review
  • Build together

Midday — Customize + Build

  • Review & Questions
  • Make It Yours: Customize your game
  • Add Something Extra: Pick a feature, effect or idea you haven't tried yet

Afternoon — Build + Test

  • Keep building & customizing
  • Test someone else's game
  • Use feedback to fix & improve yours

Vocab

MVP testing polish iteration

Friday

Ship It!

"You built it. Now it's time to share it."

Goals

  • Get your game ready to ship
  • Practice showing & explaining what you built
  • Share your game!

Morning — Finish + Polish

  • Final Build: Finish what matters most
  • Test & Fix: Find bugs and polish your game
  • Prepare your game for the showcase

Midday — Test + Practice

  • Final Testing: Play each other's games
  • Share Our Games: Rose, Bud & Thorn
  • Get Ready: Make any last fixes before the showcase

Afternoon — Showcase

  • Share our games & celebrate our wins!
