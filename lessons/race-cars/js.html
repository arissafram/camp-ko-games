JavaScript

JavaScript makes the page do things. Our game needs to track each car's position, listen for key presses, move the right car, and check for a winner.

Variables

A variable stores a value we plan to change later — like how far along the track a car has moved.

let ↑ keyword — makes a variable we can update
car1Position ↑ the variable's name
= 0 ↑ starting value

In practice, a variable looks like this:

let car1Position = 0;
let car2Position = 0;

Finding elements

To find an element on the page and control it, we use getElementById — it finds the one element whose id attribute matches.

document.getElementById('car1') ↑ finds player 1's car, so we can move it
document.getElementById('car2') ↑ finds player 2's car
document.getElementById('result') ↑ finds the message paragraph, so we can announce a winner

Listening for key presses

An event listener waits for something to happen, then runs a function. We listen for keydown on the whole window, then check event.key to see which key was pressed.

'keydown' ↑ the event — fires every time a key is pressed
event.key ↑ which key was pressed, as text like 'a'
if (event.key === 'a') ↑ only move player 1's car if it was the 'a' key

Moving a car

Each key press adds to that player's position, then writes it onto the car's left style — the same left we set up with position: absolute in CSS.

car1Position += 20 ↑ add 20 to the running total
car1.style.left ↑ the CSS left property, controlled from JS
car1Position + 'px' ↑ CSS needs units — 'px' means pixels

Checking for a winner

An if statement only runs its code when a condition is true. We use >= ("greater than or equal to") to check if a car has reached — or fully crossed — the finish line, which is drawn as its own line partway down the track, well before the track's edge.

const finishLine = 600;

if (car1Position >= finishLine) {
    result.textContent = 'Player 1 wins!';
}

Once someone wins, the cars shouldn't keep moving. We add a gameOver variable that starts as false, flip it to true the moment a car wins, and check it at the very top of moveCars — if the game is already over, we return before anything else can happen.

let gameOver = false; ↑ starts false — the race is still on
if (gameOver) { return; } ↑ stops the function early, before any key can move a car
gameOver = true; ↑ set the moment a car wins

Get started

These challenges aren't part of the race game — they're just about getting comfortable with booleans and if / else before we use them for real. Press F12 to open the console, then try each one in your script.js file.

Booleans

A boolean is a value that's only ever true or false. Comparisons — like >, <, and === — always produce a boolean.

true / false ↑ the only two boolean values
10 > 3 ↑ a comparison — evaluates to true
10 < 3 ↑ evaluates to false

if / else

An if runs its code when the condition is true. Add an else to run different code when it's false — one branch or the other always runs, never both.

let age = 15;

if (age >= 13) {
    console.log('Teenager');
} else {
    console.log('Kid');
}
