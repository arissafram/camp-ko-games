Something's not working... how can I fix it?

Common reasons my code isn't working.

HTML

  • ❌ Misspelled a tag

    e.g. <buton> instead of <button>

  • ❌ Forgot to close a tag

    e.g. <p>Hello instead of <p>Hello</p>

  • ❌ Forgot quotation marks around an attribute

    Needs double quotes — e.g. class=track instead of class="track"

  • ❌ Forgot to save

    Ctrl + S

CSS

  • ❌ Forgot the semicolon

    Every style needs to end in a semicolon

  • ❌ Misspelled a property name
  • ❌ Changed HTML instead of CSS

    HTML is the structure, CSS is the style

  • ❌ Forgot the curly braces

    All styles are wrapped in { ... }

  • ❌ Selector doesn't match the element

    Check your element type, class name, or id

  • ❌ Forgot to save

    Ctrl + S

JavaScript

  • ❌ Misspelled a variable or function name

    e.g. scoreElemnt instead of scoreElement

  • ❌ Forgot quotation marks around a string

    e.g. console.log(Hi!) instead of console.log("Hi!")

  • ❌ Used the wrong id

    e.g. getElementById("Score") when the HTML says id="score" — case matters!

  • ❌ Forgot the parentheses when calling a function

    e.g. clickButton instead of clickButton()

  • ❌ Forgot to save

    Ctrl + S
