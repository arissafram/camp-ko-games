🏎️ Race Cars

Today we'll learn the basics of HTML, CSS, and JS while making a two player Race Cars game. Here's a simple example below, but you'll add your own flair and make it your own.

Starter HTML

Every page starts the same way. Copy this into your own index.html file and build inside the body.

<!DOCTYPE html>
<html lang="en">
<head>
    <title>My Race Cars Game</title>
    <link rel="stylesheet" href="styles.css">
    <script src="script.js" defer></script>
</head>

<body>
    <!-- Your HTML goes in here -->
</body>
</html>

Our Goals

  1. Build the track
    1. Add a header
    2. Add a track for each player — a div works great
    3. Add a car inside each track, with its own id
    4. Add a place for the result message to show up
  2. Add styles
    1. Give each track a size and a border
    2. Make the track position: relative
    3. Make each car position: absolute so it can move
    4. Hide anything that spills outside the track
  3. Add actions
    1. Listen for key presses on the page
    2. Move the right car when its key is pressed
    3. Check if a car has reached the finish line
    4. Show who won
  4. Challenges
    1. Change how far each key press moves the car
    2. Move the finish line closer or farther away
    3. Change the car emojis
    4. Add a "Reset" button to race again
