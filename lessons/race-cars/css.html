CSS

CSS changes how the page looks. It turns two plain divs into a track with borders, and gives us a way to slide a car across it.

How to Write CSS

Every CSS rule is written the same way — a selector, curly braces, and a property with a value that ends in a semicolon.

.track ↑ selector — matches every element with class="track"
{ ↑ opening curly brace
border: 3px solid white; ↑ property: value;
} ↑ closing curly brace

Here are two real rules from our game — div selects every <div> on the page, and #car1 selects only the one element with id="car1".

div {
    text-align: center;
    font-family: Tahoma, sans-serif;
}

#car1 {
    position: absolute;
    left: 0;
}

Helpful CSS Properties

Here are the properties we used to build our track, with an example of what each one actually does.

font-family

font-family: monospace;

Sets the font used for text on the page.

text-align

text-align: center;

Lines text up along the left, right, or center of its box.

border

border: 3px solid white;

Draws a line around the edge of an element — that's the edge of our track.

width / height

width: 700px; height: 80px;

Sets how big a box is — that's how we control the size of the track.

→

transform

transform: scaleX(-1);

Flips, rotates, or resizes an element without changing the page's layout. scaleX(-1) mirrors it left-to-right — that's how our cars end up facing the direction they're driving.
