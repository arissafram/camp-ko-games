HTML

HTML creates the things you see on the page — our two race tracks, the cars inside them, and the result message.

How to Write HTML

Every HTML element is written the same way — an opening tag, the content inside it, and a closing tag.

<h1> ↑ opening tag
Two Player Race ↑ content
</h1> ↑ closing tag

Sometimes elements contain other elements. Our track is a <div> with another <div> nested inside it for the car.

<div class="track">
    <div>🏎️</div>
</div>

Attributes

Elements can carry extra information inside their opening tag, called an attribute. We need to tell our two cars apart, so JavaScript can move the right one — that's what id is for.

<div ↑ the tag
id="car1" ↑ attribute name, then a value in quotes
> ↑ end of the opening tag

Every id on a page has to be unique — no two elements can share one. That's how car1 and car2 stay two separate, movable cars.

<div class="track">
    <div id="car1">🏎️</div>
</div>

<div class="track">
    <div id="car2">🚙</div>
</div>

Common HTML Tags

Tag What It Creates Example
<h1> A large heading <h1>Two Player Race</h1>
<p> A paragraph of text <p>Player 1: Press A</p>
<div> A generic container for grouping other elements together — this is our track and our cars <div class="track">...</div>
