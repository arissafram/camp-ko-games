JavaScript

JavaScript makes the webpage interactive. It tells the page what to do when someone clicks, types, or moves the mouse.

How to Write JavaScript - setTimeout

setTimeout() waits a set amount of time, then runs some code.

setTimeout ↑ keyword — waits, then runs code
function() { ... } ↑ the code that runs after waiting
2000 ↑ how long to wait, in milliseconds 
setTimeout(function () {
  // do something
}, 2000);
