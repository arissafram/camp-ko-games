JavaScript

JavaScript makes the webpage interactive. It tells the page what to do when someone clicks, types, or moves the mouse.

How to Write JavaScript - Variables, Selectors, functions

A variable stores a value so you can use it later. If the value has quotes around it, it's called a string. If it's a number, it's called a number.

let score = 0; ↑ let — value can change
"Pickle" ↑ string — text
10 ↑ number — a number

A selector finds an element on the page so JavaScript can use it.

document.querySelector("button") ↑ finds the first matching element
document.querySelector("#score") ↑ finds the element with id="score"

A function is a reusable block of code.

function ↑ keyword
sayHi ↑ function name
() ↑ parentheses
{ ... } ↑ the code that runs

Common JavaScript Concepts

Concept What It Does Example
Selector Finds an element on the page so JavaScript can use it document.querySelector("button");
Variable Stores a value that can change later let score = 0;
String A value that's text let name = "Pickle";
Number A value that's a number let score = 10;
Function A reusable block of code that runs when it's called 
function sayHi() {
  console.log("Hi!");
}
