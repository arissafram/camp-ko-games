JavaScript

JavaScript makes the webpage interactive. It tells the page what to do when someone clicks, types, or moves the mouse.

How to Write JavaScript - Booleans & conditionals

A boolean is a value that's either true or false.

true ↑ yes / on
false ↑ no / off

Booleans can also be stored as variables.

let isGameOver = true; ↑ a variable that stores a boolean

Conditionals let your code make decisions.

if ↑ keyword
(score >= 10) ↑ condition — true or false
{ ... } ↑ runs if true
else { ... } ↑ runs if false 
if (score >= 10) {
  // do something
} else {
  // do something else
}

Common JavaScript Concepts

Concept What It Does Example
Boolean A value that's true or false let gameOver = false;
Conditional Runs different code depending on whether something is true or false if (score >= 10) { ... } else { ... }
