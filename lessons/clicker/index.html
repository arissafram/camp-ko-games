Clicker Game

Throughout the week we'll learn the basics of HTML, CSS, and JS while making a clicker game. Here's a simple example below, but each of us will add our own flair and make it our own.

Our Goals

  1. Build a game board
    1. Header
    2. Description
    3. Button
    4. Image or a link
  2. Add styles
    1. Background color
    2. Font color
    3. Font size
    4. Height/width
  3. Add actions
    1. Update the score when the button is clicked
    2. Display the updated score on the screen
  4. Challenges
    1. Add a countdown timer
    2. Save and display a high score
    3. Show a "You win!" message once the score reaches a certain number
    4. Add more content to your game board - background image? more buttons? more p tags?
  5. Play!
    1. Play and test each other's games
