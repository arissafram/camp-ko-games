HTML

HTML creates the things you see on a webpage, including headings, paragraphs, buttons, and images.

How to Write HTML

Every HTML element is written the same way — an opening tag, the content inside it, and a closing tag.

<p> ↑ opening tag
Hello ↑ content
</p> ↑ closing tag

Sometimes elements are self-closing.

<img src="..." /> ↑ self-closing tag with an attribute

Sometimes elements contain many elements.

<div>
    <p>Some text</p>
    <button>
        <img src="..." />
    </button>
</div>

Common HTML Tags

Tag What It Creates Example
<main> The main content of the page. Everything we add is inside of these tags. <main>...</main>
<h1> A large heading <h1>My Clicker Game</h1>
<p> A paragraph of text <p>Click the button to play!</p>
<button> A button the player can click <button>Click Me</button>
<img /> A picture <img src="spongebob.png" alt="SpongeBob">
<a> A clickable link to another page or site <a href="https://example.com">Visit</a>
<div> A generic container for grouping other elements together <div class="card">...</div>

Explore more tags here — w3schools.com.

IDs and Classes

Sometimes elements can have an id or a class to make them easier to select and style.

<p id="score"> ↑ id — unique, only one per page
<button class="game-button"> ↑ class — can be reused on many elements

Learn more about ids and classes here — ids, classes.
