CSS

CSS changes how the webpage looks. It controls colors, fonts, sizes, spacing, and borders.

How to Write CSS

Every CSS rule is written the same way — a selector, curly braces, and a property with a value that ends in a semicolon.

button ↑ selector
{ ↑ opening curly brace
color: purple; ↑ property: value;
} ↑ closing curly brace

Sometimes we target elements by their id.

#score { color: red; } ↑ id selector — matches the element with id="score"

Sometimes we target elements by their class.

.game-button { color: red; } ↑ class selector — matches every element with class="game-button"

Common CSS Properties

Property What It Changes Example Other Values
background-color The background color background-color: lavender; pink, skyblue, #ff0000
color The text color color: blue; red, green, #333
font-size The size of the text font-size: 40px; 16px, 24px, 72px
font-family The font used for the text font-family: Tahoma; Arial, Georgia, sans-serif
width How wide something is width: 200px; 100px, 250px, 50%
height How tall something is height: 200px; 100px, 250px, 50%
border The border around something border: 10px solid black; 2px dashed red, 5px solid blue
padding Space inside an element padding: 20px; 10px, 40px
margin Space outside an element margin: 20px; 10px, 40px, auto
text-align Where the text is placed text-align: center; left, right
cursor How the mouse cursor looks cursor: pointer; grab, help, not-allowed

More CSS Tricks

All of the designs you see on the web come from CSS. Here are a few fun ones to try, but you can Google anything else you can think of. If you can dream it, you can build it.

Circle

border-radius: 50%;

Turns a square into a circle.

Dotted Border

border-style: dotted;

Makes the border a row of dots instead of a solid line.

Drop Shadow

box-shadow: 5px 5px 10px gray;

Adds a soft shadow behind an element.

Tilt

transform: rotate(15deg);

Rotates an element.

Color Gradient

background: linear-gradient(to right, pink, purple);

Blends two colors together as a background.

Animation

animation: spin 5s linear infinite;

Makes an element move, spin, or change over time.
