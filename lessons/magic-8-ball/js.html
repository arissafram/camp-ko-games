JavaScript

JavaScript makes the page do things. Our ball needs a list of possible answers, and a way to pick one at random when it's clicked.

Arrays

An array is a list of values, written inside square brackets and separated by commas.

let answers ↑ a variable that holds the list
[ ] ↑ square brackets — this is an array
'Yes', 'No', 'Maybe' ↑ items, separated by commas

In practice, a list looks like this:

let answers = ['Yes', 'No', 'Maybe'];

Every item in an array has a position, called its index. Counting starts at 0, not 1.

let colors = ['red', 'yellow', 'blue', 'green'];
Index colors[index]
0colors[0] → "red"
1colors[1] → "yellow"
2colors[2] → "blue"
3colors[3] → "green"

Finding elements

To find an element on the page and control it, we use querySelector. We need to find two elements — the ball itself, so we know when it's clicked, and the answer paragraph inside it, so we can change its text.

document.querySelector("button") ↑ finds the outer ball, so we can listen for clicks
document.querySelector("p") ↑ finds the inner circle, so we can change its text

Picking a random answer

To pick a random item from the array, we use Math.random() to get a random index.

Math.random() ↑ random decimal between 0 and 1
answers.length ↑ how many items are in the array
Math.floor(...) ↑ rounds down to a whole number, so we get a valid index
